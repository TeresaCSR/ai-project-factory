## Recovery boundary

Project-local changes that are recoverable through verified Git history,
worktrees, backups, or snapshots are pre-authorized. Anything outside that
boundary must be listed below or requires a stop.

## Pre-authorized external effects

- None by default.

## Contract invalidation

A change invalidates this Contract only if it makes the approved outcome, a
required deliverable, a hard constraint, the project boundary, or an
acceptance criterion no longer true. Internal architecture changes, retries,
dependency replacements, and ordinary implementation detours do not invalidate
the Contract unless explicitly declared as hard constraints.

## Amendment policy

User steering may amend this Contract. Record the revised baseline and rationale
instead of silently replacing the old agreement.
